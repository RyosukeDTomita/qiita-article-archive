## やりたいこと: Zedのvimプラグインのキーをカスタマイズしたい

https://qiita.com/sigma_devsecops/items/763c109c332d85d9686c

以前、VS CodeからZedに移行したのですが、vimモードのキーバインドをどうしても変えたくなったので、修正方法を防備録として書いておく

---

## 環境

- ホストOS: Ubuntu 24.04 LTS
- Zed 1.7.2 aa8ac4b04e261f19c2465f68e9ce2fa9721ae1a2

---

## 解決方法

現状、Zedのvimモードにvimrcを使う機能はなさそう。

クリップボード共有なんかは特に設定しなくてもできるので、最低限これだけあれば耐えるなと思った。

```
nnoremap k gk
nnoremap j gj
nnoremap gk k
nnoremap gj j
```

zedの設定ファイルに以下を記載したらうまくいった。

```~/.config/zed/keymap.json
[
  {
    "context": "VimControl && !menu",
    "bindings": {
      "j": ["vim::Down", { "display_lines": true }],
      "k": ["vim::Up", { "display_lines": true }],
      "g j": ["vim::Down", { "display_lines": false }],
      "g k": ["vim::Up", { "display_lines": false }]
    }
  }
]

```
